# Local cutout engine (OPT-IN) — CPU-only BiRefNet ONNX background remover.
#
# These are NOT part of the base runtime (requirements.txt). Install them ONLY
# when enabling LOCAL_CUTOUT_ENGINE_ENABLED=1, then stage the model with
#   python scripts/prepare_cutout_model.py
#
# Deliberately minimal: the engine runs the BiRefNet ONNX model directly through
# onnxruntime with numpy + Pillow. rembg is intentionally NOT used at runtime
# (it pulls ~30 native packages — numba, llvmlite, scipy, scikit-image,
# pymatting — plus an uncontrolled first-request model download). Pillow is
# already declared in requirements.txt.
#
# Pins verified on Python 3.11 / Windows x86_64 (spike 2026-08-10):
#   onnxruntime 1.28.0, numpy 2.4.6.
onnxruntime>=1.22,<2
numpy>=1.26,<3
